# important-talks-video-downloader

Пользовательский скрипт для браузерных расширений управления скриптами (например, Tampermonkey), добавляющий кнопку пакетной загрузки видеоматериалов с портала «Разговоры о важном».

## Установка и запуск

1. Установите расширение для управления пользовательскими скриптами (например, Tampermonkey) в браузер.
2. Добавьте в расширение локальный скрипт [`important-talks-video-downloader.user.js`](important-talks-video-downloader.user.js).
3. Откройте страницу темы с якорем нужной возрастной группы или класса (например, `#klass_spo2-4`) и нажмите появившуюся кнопку «Скачать все видео».
